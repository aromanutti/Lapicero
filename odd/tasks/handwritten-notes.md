# Handwritten notes V1

## Objective
Build Lapicero for Windows 10/11 as a personal tablet-first handwritten note app for an engineering student. Organize content as Subjects (Materias) → Sections (Secciones) → Pages (Hojas); drawing happens on a page. Notes are handwritten only; typed text and pressure-sensitive stroke width remain out of scope.

## Decisions and constraints
The first Tkinter version implemented local JSON v1 note storage, whole-stroke erasing, undo/redo, five pen colors, width 1–20, shortcuts, and hold-to-snap (~500 ms) for circles, triangles, squares, rectangles, and arrows. The user tested it and reported pixelated handwriting. The data is stored as coordinate strokes, but Tk Canvas draws unsmoothed line segments. The user explicitly chose a PySide6/Qt migration over partial Tk smoothing and fixed A4-style pages over an infinite canvas. Use antialiased floating-point paths and tablet events where available; keep mouse input. Reuse `lapicero/model.py` and `lapicero/shapes.py` and retain JSON v1 compatibility. PySide6 is not installed; install only into ignored project `.venv`, record a dependency, and do not modify the global Python environment. PySide6 6.11.2 supports Python 3.14 and Windows wheels per PyPI. Qt sources: https://doc.qt.io/qtforpython-6/PySide6/QtGui/QPainter.html and https://doc.qt.io/qtforpython-6/PySide6/QtGui/QTabletEvent.html . Leave unrelated pre-existing untracked `.mcp.json`, `profiles.export.json`, and `odd/tasks/gpt6-profile.md` untouched. No commit without explicit user authorization.

## Acceptance and checks
- Navigate subjects → sections → pages; create and rename them, select a page to draw, and keep each page's content distinct and locally persistent. Each page is a fixed-size A4-style canvas; creating the next page is explicit.
- Draw crisp antialiased handwriting live and after save/reopen; a tap remains visible; pen widths and colors apply to new strokes. Geometry remains re-renderable from original points, not flattened into a bitmap.
- Mouse and tablet event streams must not duplicate one physical stroke. A 500 ms endpoint hold previews one clean supported shape; quick release keeps handwriting; movement cancels stale preview.
- Whole-stroke erasing groups one drag into one undo step; shapes and ink are undoable, redoable, saveable. New/open/close preserve unsaved-work prompts and failures never replace unowned data silently.
- Retain the five swatches, width 1–20, P/E, Ctrl+Up/Down, Ctrl+Z/Y, Ctrl+N/O/S shortcuts; canvas-only shortcuts require canvas focus and dialogs suppress shortcuts. Update the guide with installation and V1 limits.
- Automated model/shape tests remain green; rewrite Tk GUI tests for Qt and add renderer/event/hold tests. Launch a Qt window successfully. Real tablet behavior and visual appearance still require the user's manual trial.
