# OneNote-style canvas
Objective: lightweight OneNote replacement — infinite canvas, OneNote-like drawn toolbar (pens, eraser, lasso, shapes), plain/grid paper, fullscreen.
Branch: feat/handwritten-notes · Delivery: ask-on-risk, no commits without explicit user authorization (standing user constraint from handwritten-notes.md) · Runner: `.venv/Scripts/python -m pytest -q` (QT_QPA_PLATFORM=offscreen).

## Specs
- S1 "Necesito que los pens,eraser y demas esten con dibujo como en one note" — toolbar tools are drawn icons (pen bodies with colored tips, eraser, lasso, shapes), not text buttons.
- S2 "eleccion entre hoja lisa y cuadriculada" — per-page paper choice: plain or grid; persisted with the page; older libraries without the field load as before (assumption: default for new pages is grid).
- S3 "Pantalla completa" — toggle fullscreen (F11 / toolbar); Esc leaves it.
- S4 "Que sea infinito y no A4 como esta ahora" — canvas grows right and down without limit; scroll (wheel, Shift+wheel, scrollbars), zoom (Ctrl+wheel, Ctrl+0); ink is no longer clamped to A4.
- S5 "unos atajos como la barra de arriba, con lapiz, goma,seleccionador libre y formas" — top toolbar with undo/redo, lasso (free selection: select, drag to move, Delete to remove, undoable), eraser, pen presets incl. highlighter, shapes (line, arrow, rectangle, ellipse, triangle by dragging).
- Assumption: existing hold-to-snap, shortcuts P/E, Ctrl+Up/Down, Ctrl+Z/Y/N/O/S and persistence guarantees stay.
